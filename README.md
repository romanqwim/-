🇷🇺 Русская версия

Описание

Привет! Хочешь понизить свою самооценку до нуля? Тогда бери мой исходник.

Программа задаёт тебе абсурдные вопросы, а ты отвечаешь "ДА" или "НЕТ". После каждого ответа ты узнаёшь, на какой именно вопрос ответил, и получаешь жёсткую, смешную и беспощадную реакцию. Твоя самооценка будет уничтожена за считанные минуты!

⚠️ Предупреждение: После прохождения этой игры тебе понадобится личный психолог (хотя у тебя всё равно не хватит на него денег).

📊 Что нового в v1.1

· ✅ 30 вопросов (было 25)
· ✅ 25 смешных фраз (было 20)
· ✅ Полный рефакторинг кода
· ✅ ООП архитектура
· ✅ Счётчик разрушенной самооценки
· ✅ Особые сценарии (продолжение для IQ, Контракт души)
· ✅ Улучшенная обработка ошибок
· ✅ Подсказки типов

🎮 Как играть

```bash
python Ego_Destroyer_v1.1_RU.py
```

· Пиши "да" или "нет" для ответа на вопросы
· Пиши "стоп" для выхода из игры
· Отвечай честно — игра всё равно узнает правду! 😈

🛠️ Установка

```bash
git clone https://github.com/ваш-юзернейм/ego-destroyer.git
cd ego-destroyer
pip install -r requirements.txt
```

🇬🇧 English Version

Description

Hey there! Want to crush your self-esteem down to zero? Then grab my source code!

The game asks you ridiculous questions, and you answer "YES" or "NO". After each answer, you find out which question you responded to and get a brutal, funny, and merciless reaction. Your self-esteem will be destroyed in minutes!

⚠️ Warning: After playing this game, you're going to need a personal therapist (though you probably can't afford one anyway).

📊 What's New in v1.1

· ✅ 30 questions (up from 25)
· ✅ 25 funny phrases (up from 20)
· ✅ Full code refactoring
· ✅ OOP architecture
· ✅ Self-esteem destruction counter
· ✅ Special scenarios (IQ follow-up, Soul Contract)
· ✅ Improved error handling
· ✅ Type hints for better code

🎮 How to Play

```bash
python Ego_Destroyer_v1.1_EN.py
```

· Type "yes" or "no" to answer questions
· Type "stop" to exit the game
· Answer honestly — the game will find out the truth anyway! 😈

🛠️ Installation

```bash
git clone https://github.com/your-username/ego-destroyer.git
cd ego-destroyer
pip install -r requirements.txt
```
